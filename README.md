## Fol-archived

A new Coq formalisation of classical first-order logic.
The Hilbert calculus is proved sound, and complete for languages with countably many function, constant and relation symbols;
the only axiom used is `classic : forall P : Prop, P \/ ~ P`.

- Lim, Kijeong. "A New Coq Formalisation of Classical First-Order Logic with Proofs of the Soundness and Completeness Theorems." 한국정보과학회 학술발표논문집 (2024): 1175-1177.
- Talk at The Fourth Korea Logic Day, January 14, 2025: [slides](Pdf/TheFourthKoreanLogicDay_KijeongLim.pdf).

## ppap

> Projects Pouring All Power.

Haskell research projects behind one executable, `ppap`.

- `Hol`: a λProlog-style logic programming language with higher-order abstract syntax, typed terms, modules, notations, Presburger arithmetic constraints and a debugging REPL; the default implementation is `Hol.BETA`.
- `V1` (also `Hol --v1`): a bytecode compiler for the same language and a native search engine in C (βη-normalisation, higher-order pattern unification, backtracking, cut), with no fallback to the BETA interpreter; compiled queries can be saved and replayed.
- `ALPHA1`: the final legacy Aladdin implementation, revived with natural-number arithmetic.
- `LGS`, `PGS`: a lexer generator and a parser generator; the lexers and parsers of `Hol` are generated by them.
- `Calc`: Presburger arithmetic and control-system diagrams.

```bash
cd ppap
cabal build ppap
printf 'Hol --test\nexample/fibonacci\n?- main N.\n:q\n\n' | cabal run -v0 ppap
```

See [the README of `ppap`](https://github.com/KiJeong-Lim/ppap#readme) for the REPL, the dispatcher commands and the tests.
